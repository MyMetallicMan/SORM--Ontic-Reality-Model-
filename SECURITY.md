# Security Policy

## Supported Versions

Only the latest stable release (v13.0 and above) is actively supported with security updates.

| Version | Supported |
|---------|-----------|
| 13.x    | ✅ Yes    |
| 12.x    | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository (e.g., exposure of sensitive information, license violation, or any issue that could compromise the integrity of the work), please report it directly to the maintainer:

- **Contact:** [metallicman.com](https://metallicman.com)
- **Do not** open a public issue for security concerns.

You can expect acknowledgment of your report within 48 hours and a resolution timeline based on the severity of the issue.

## Notes

This repository contains a theoretical framework, not executable software. Security concerns are primarily around:

- Unauthorized attribution or license violations
- Exposure of private communication
- Misrepresentation of the work

We take all reports seriously and will respond accordingly.
